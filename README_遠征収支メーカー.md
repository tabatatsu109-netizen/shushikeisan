# 遠征収支メーカー 運用README

チームの遠征・合宿・大会の収支計画書/収支報告書Excelを、フォーム入力だけで作るツールです。
本体は `遠征収支メーカー.html` の1ファイルのみ。サーバー・アカウント・ネット接続は不要です(ライブラリはファイル内に埋め込み済み。入力内容はどこにも送信されません)。

## 配布方法

`遠征収支メーカー.html` をそのままLINE・メール・共有フォルダでスタッフに渡すだけです。受け取った人はダブルタップ(PCならダブルクリック)でブラウザが開けば使えます。パソコン(Chrome/Edge)・Android(Chrome)・iPhone(Safari)に対応。

## 基本の流れ

1. **遠征前(計画)**: 「収支計画」モードで基本情報を入力 → 項目はプルダウンか「タップで追加」チップで選択 → 単価と数量を入力(金額は自動計算)→ 選手数を入れると1人あたり負担金の目安が提案されるので「反映」ボタン →「Excelを作成」または「🖨 印刷/PDF保存」。
2. **遠征後(報告)**: 「収支報告」に切り替えると計画額が引き継がれる → 実績列に金額を入れるだけ(差額は自動)→「Excelを作成」。
3. **引き継ぎ・途中保存**: 「データ保存」で出るJSONファイルを保管。別の人が「データ読込」すれば続きから作業できます。**計画を作った人と精算する人が別でもこのファイルを渡せばOK。**

## 入力のコツ(対応している書き方)

- 数字は**全角でもOK**(９５００→9500)。カンマ入り(9,500)もOK。
- 数量は「38」のほか「4日」「20名×4日」「２０名ｘ２日」も自動計算されます。
- 「一式」など計算できない数量のときは、金額欄に直接金額を入れてください(誤計算防止のため、解釈できない数量は自動計算しません)。
- 金額欄に直接入力すると、単価×数量より優先されます。
- 生成されるExcelは数式入りなので、あとからExcel上で単価を直しても合計は自動再計算されます。
- 「🖨 印刷/PDF保存」は、ブラウザの印刷画面が開きます。プリンタの代わりに**「PDFに保存」**を選べばPDFファイルになります(スマホは共有メニューから「PDFとして保存」等)。入力欄やボタンは印刷されず、Excelと同じ見た目のA4書類だけが出ます。

## テスト項目(新しい端末・ブラウザで配布前に確認)

- [ ] 計画モード: 単価×数量の金額自動表示と支出合計・収入合計・収支差額が正しい
- [ ] 全角数字(９５００など)で入力しても合計に反映される
- [ ] 「20名×4日」形式の数量が正しく計算される
- [ ] 選手数入力→負担金の目安が表示→「反映」で収入に入る
- [ ] 「Excelを作成」でファイルがダウンロードされ、Excelで開ける(警告・エラーなし)
- [ ] Excel側で単価を変更すると合計が再計算される
- [ ] 「データ保存」→ページを開き直して「データ読込」で内容が完全に復元される
- [ ] 「収支報告」切替で計画額が引き継がれ、実績入力で差額(超過は赤)が出る
- [ ] 収入または支出が空のままExcel出力してもエラー・循環参照が出ない
- [ ] スマホ(幅375px)で表が横スクロールでき、レイアウトが崩れない
- [ ] 「🖨 印刷/PDF保存」で印刷プレビューにA4の書類レイアウトが表示され、入力画面が印刷されない(計画・報告の両モード)

## 既知の注意点

- iPhoneのSafariではダウンロードしたExcelが「ファイル」アプリに保存されます(初回だけ場所を確認してください)。
- ブラウザを閉じると入力中の内容は消えます。長い入力の途中では「データ保存」をこまめに。
- 選手数を後から変えた場合、負担金の数量は自動では変わりません。提案の「反映」ボタンを押し直してください。

## 技術メモ(直したい人向け)

単一HTML内に UI(素のJS)+ ExcelJS(MIT License)を埋め込み。データ構造は `{mode, info, note, expenses[], incomes[]}`、行は `{item, unitPrice, qty, amount, actual, note}`。JSON保存ファイルはこの構造そのままなので、他ツールからの生成も可能。Excel書式は ＭＳ Ｐゴシック/緑ヘッダー(D9EAD3)/¥表示/A4縦・横1ページ印刷設定。
